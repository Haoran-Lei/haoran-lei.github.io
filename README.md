# Haoran Lei - Engineering Portfolio

A concise job-application portfolio covering robotics software, embedded systems, controls, perception, hardware integration, and education.

## Publish with GitHub Pages

1. Create a GitHub repository and place these files at its root.
2. Push to the `main` branch.
3. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**.

The included workflow publishes the site automatically after each push to `main`.

## Local preview

Serve the directory with any static web server and open the local URL in a browser.
